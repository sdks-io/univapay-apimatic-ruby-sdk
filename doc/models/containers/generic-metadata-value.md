
# Generic Metadata Value

Allowed values for metadata properties.

## Data Type

`String | Float | TrueClass | FalseClass`

## Cases

| Type |
|  --- |
| `String` |
| `Float` |
| `TrueClass \| FalseClass` |

## String

### Initialization Code

#### Example

```ruby
value = 'sale'
```

## Float

### Initialization Code

#### Example

```ruby
value = 10
```

## TrueClass | FalseClass

### Initialization Code

#### Example

```ruby
value = true
```
